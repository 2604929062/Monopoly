# 新城地产局规则基线

版本：v1.0 草案  
日期：2026-11-06  
状态：作为后续开发与试玩的统一规则参照

## 1. 游戏定位

《新城地产局》是一款 4-8 人在线地产经营游戏，也支持 1 名真人挑战 3 名 AI。
游戏保留经典大富翁的核心循环：掷骰移动、购买地产、收取租金、完成街区、扩大资产。
在此基础上加入事件牌、拍卖、监狱、建筑和地产抵押。

游戏目标不是单纯追求最高现金，而是在规定回合内建立最高城市资产；如果玩家陆续破产，则最后一名未破产玩家获胜。

## 2. 游戏模式

### 简化版

- 使用紧凑棋盘。
- 目标时长约 20-40 分钟。
- 回合上限为 18 轮。
- 保留买地、租金、事件、拍卖和基础监狱规则。
- 暂不强调房屋建设和复杂经营。

### 复杂版

- 使用完整棋盘。
- 目标时长约 40-60 分钟。
- 回合上限为 30 轮。
- 开放街区垄断、房屋建设、拍卖、事件、监狱、抵押、贷款、交易和城市议会。
- 更复杂的事件牌仍作为后续扩展。

## 3. 开局

- 每名玩家初始拥有 1500 城币。
- 每名玩家从起点出发。
- 玩家没有初始地产、房屋或贷款。
- 普通房间需要 4-8 名玩家。
- 单人挑战由服务端补入 3 名 AI，AI 使用同一套规则。
- 骰子、事件牌、租金和资金变化均由服务端裁定。

## 4. 回合流程

当前玩家按以下顺序行动：

1. 检查是否在监狱。
2. 正常玩家掷两个骰子并移动。
3. 结算经过起点、落点和对应的地产/事件效果。
4. 如果出现购买、拍卖或监狱处理，完成对应操作。
5. 当前玩家可以在结算阶段抵押符合条件的地产。
6. 玩家结束回合，轮到下一名未破产玩家。
7. 所有玩家都行动一次后，轮数增加一轮。

当前版本没有“双骰再次行动”，后续作为规则选项评估。

## 5. 棋盘格效果

### 起点

玩家经过起点时获得 200 城币。当前版本只要移动路径跨过起点就触发，不要求停在起点。

### 未拥有地产

玩家可以选择购买：

- 支付标价。
- 获得该地产所有权。
- 进入回合结算阶段。

玩家也可以放弃购买：

- 该地产进入拍卖。
- 其他玩家按顺序出价或弃拍。
- 出价最高者支付成交价并获得地产。
- 所有人弃拍时，地产保持无人拥有。

### 已拥有地产

- 自己的地产：不支付租金。
- 他人的普通地产：支付当前租金。
- 抵押地产：租金为 0。

### 税费格

按照格子显示金额支付公共费用。

### 事件格

由服务端随机抽取事件牌，立刻结算现金或状态效果。当前已实现的事件为现金收入/支出事件，后续扩充为个人、街区和全城事件。

### 监狱格与前往监狱格

- 停在监狱格不会自动入狱。
- 到达“前往监狱”后直接移动到监狱并结束本回合。

## 6. 监狱规则

玩家入狱后，每次轮到自己时有两种选择：

- 尝试掷对子：掷出相同点数即可免费出狱并按点数移动。
- 支付 50 城币保释：立即出狱并掷骰移动。

连续两次未掷出对子时，本回合结束。第三次尝试仍失败时，强制支付 50 城币并移动。

## 7. 街区和房屋

复杂版中，玩家拥有一个街区的全部地产后，获得街区垄断：

- 未建房地产的租金翻倍。
- 可以在自己的回合结算阶段建设房屋。
- 房屋必须均衡建设。
- 每处地产最多 4 级房屋。
- 建房费用约为地产价格的一半。

当前租金倍率为：

| 房屋等级 | 租金倍率 |
| --- | ---: |
| 0 级 | 1 倍 |
| 1 级 | 3 倍 |
| 2 级 | 6 倍 |
| 3 级 | 10 倍 |
| 4 级 | 15 倍 |

有房屋的地产不能直接抵押。

## 8. 地产抵押

玩家在自己的回合结算阶段可以抵押没有房屋的自有地产：

- 获得地产价格 50% 的现金。
- 所有权保留。
- 抵押期间不收租。
- 当前版本没有赎回功能，赎回和抵押利息将在后续规则阶段补充。

## 9. 胜负

### 资金不足与破产

- 玩家需要支付租金、税费、事件支出或其他债务时，系统先使用手头现金。
- 现金不足时，系统自动清算玩家的地产价值来补足欠款；清算顺序优先处理没有房屋的地产。
- 欠租时，清算出的地产转给收租玩家；欠税、负面事件或银行债务时，清算出的地产回到银行。
- 清算仍不足以偿还欠款时，玩家破产，现金归零并退出正常行动顺序。
- 破产玩家的剩余地产归收款方或银行，贷款记录移除。
- 当前版本不允许玩家通过负现金继续游戏。

### 提前结束

如果只剩一名未破产玩家，该玩家获胜。

### 达到回合上限

达到回合上限后，按净资产结算。当前实现为：

```text
净资产 = 现金 + 未抵押地产价格 + 房屋价值 - 贷款债务
```

贷款债务目前尚未接入，房屋价值和抵押地产计价方式需要在贷款系统开发前统一实现。

## 10. 银行借贷

当前版本每名玩家最多同时持有一笔贷款：

- 贷款档位为 200、500、1000 城币。
- 对应每轮利息为 20、60、140 城币。
- 借款和还款都只能在自己的回合结算阶段执行。
- 每轮所有玩家各行动一次后，银行统一给所有贷款增加一笔利息。
- 利息不会立即从现金扣除，而是累计到贷款余额。
- 玩家可以一次性还清本金和累计利息。
- 已有贷款时不能再次借款。
- 贷款不能绕过破产，只能延缓资金压力。

后续仍需补充逾期、贷款抵押和破产优先级。

## 11. 下一阶段规则：随机事件扩充

事件牌分为四类：

- 个人事件：只影响抽牌玩家。
- 地产事件：影响某块地产或某个街区。
- 全城事件：影响所有玩家。
- 决策事件：玩家在两个收益/风险选项中选择一个。

事件设计原则：

- 正面和负面效果保持大致平衡。
- 不连续针对同一名玩家造成致命打击。
- 简化版以现金和短期移动效果为主。
- 复杂版才加入地产、贷款和城市规则变化。

## 12. 城市议会与暂缓模块

### 城市议会

城市议会仅在复杂版启用。每完成 4 轮后召开一次议会；每位未破产玩家各投一票，AI 玩家由服务端自动投票。票数最高且没有并列的政策生效 3 轮；最高票平票时，本次不启用政策。

当前政策选项为：

- **街区繁荣**：所有未抵押地产租金提高 25%，计算后向上取整。
- **宽信用期**：贷款每轮利息减半；利息仍在每轮结束时计入贷款余额。
- **起点补贴**：经过起点时，除基础 200 城币外额外获得 100 城币。

投票和政策结果由服务端裁定并同步。简化版不召开城市议会。

### 赌场

赌场暂不实现，也不属于当前规则基线。未来如评估骰子押注、公共奖池或高风险地产赌注，必须先设置下注上限、冷却次数和负期望，避免赌场成为最优策略。

## 13. 开发顺序

1. 固化本规则基线并完成现有规则测试。
2. 完善破产与最终资产结算。
3. 加入玩家交易。
4. 验证城市议会的平衡性并按试玩反馈调整。
5. 扩充个人、地产、全城和决策事件牌。
6. 最后再评估赌场，作为可选高风险模块。
